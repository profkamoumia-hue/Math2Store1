# Math2Store — GitHub Pages Landing Page

A responsive storefront landing page for Math2Store. The landing page is the front door; Payhip handles checkout and product delivery.

## Files
- `index.html` — page structure and Payhip product links
- `style.css` — responsive design
- `script.js` — mobile menu and footer year

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `Math2Store`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public Pages URL.
