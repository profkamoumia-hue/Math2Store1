# Math2Store Visual GitHub Page

This version uses the actual product cover images hosted by Payhip where available and links every card directly to the supplied Payhip product page.

Upload:
- index.html
- style.css
- script.js

Then GitHub Pages:
Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.

Product URLs are the exact links supplied for the 10 Math2Store products.
